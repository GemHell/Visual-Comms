For a more in depth overview of CSS fundamentals go to htmldog.com/guides/css/. Work through the beginner tutorials, and then the "Background Images" section in the Intermediate Tutorial.

Additionally (or alternativelty), you can use the CSS snippet below to configure your page's look and feel. Create a file named style.css and paste this code inside. You can then adjust colors, typography, spacing, and layout variables as needed.


/* This is a comment. It is a way for developers to leave notes for themselves and others who are working on the code. It doesn't affect the code or show up on your site. Below I have left comments to describe what certain CSS selectors and properties do */

/* Full page background */
body {
    background-color: #f5f5f5;
    background-image: url('images/background.jpg');
    background-repeat: no-repeat;
    background-size: cover;
    background-position: center;
    color: #1a1a1a; /* Default text color */
    margin: 0;
    padding: 0;
    font-family: 'Arial', sans-serif;
    font-size: 16px;
}

/* Link colors */
a {
    color: #0073e6; /* Link color */
    text-decoration: none;
}

/* Changes text color and adds underline on mouse hover */
a:hover {
    color: #005bb5;
    text-decoration: underline;
}

/* Heading styles */
h1 {
    color: #111111; /* Heading color */
    font-size: 36px;
    margin: 24px 0 8px;
}
h2 {
    color: #333333; /* Subheading color */
    font-size: 28px;
    margin: 16px 0 8px;
}

Now, in your html, right below the <title> tag (but above the closing </head> tag) link your CSS file to your HTML page by adding this line:

<link rel="stylesheet" type="text/css" href="style.css">

Note: you will need to add this to all of your site's pages in order for it to style your entire site.

An Example of a Very Simple Hypertext Story

Here is a very simple hypertext story built with HTML. Each page is a separate HTML file linked with <a> tags:

<!-- index.html (or story-start.html) -->
<html>
<head>
    <title>The Room</title>
    <link rel="stylesheet" type="text/css" href="style.css">
</head>
<body>
    <h1>The Room</h1>
    <p>You wake up in a room after having a strange dream that you cannot remember.</p>
    <p>There is a door on the right and a door on the left.</p>
    <p><strong>What one do you choose?</strong></p>
    <ul>
        <li><a href="right-door.html">The door on the right</a></li>
        <li><a href="left-door.html">The door on the left</a></li>
    </ul>
</body>
</html>

Each choice link points to a different HTML file (right-door.html, left-door.html, etc.) which contains the next scene and its own set of choices, creating a branching narrative.

Assignment Overview:

This homework assignment, to create a web-based non-linear story, is in two parts and counts as two homework assignments; we will be looking for a highly resolved work that builds on all of the technical and aesthetic material we've covered in class so far. For this assignment, you can use photography, illustration, montage, or simple text to create a narrative with multiple story paths that can be navigated using hyperlinks. 80% of the imagery and all of the text used must be your own original content (including the Adobe generative AI tools listed above).

Steps:

  1. Map out your narrative, using Illustrator or simply a pen and paper.
  2. Develop the imagery/text for each page.
  3. You may create a new Sites folder for this assignment or create a series of new HTML pages dedicated to this project.
  4. Make sure your homepage – index.html links to the interactive story and that all story links work as you expect.

Story Requirements:

  • There must be at least two possible endings and there must be multiple ways to get to each one.

Part 1 Submission Requirements:

Part 1 of the submission should include:

  • A brief (one or two paragraph) description of your story (What is the premise? Are there characters? Where does it take place? What are the kinds of choices you will provide to your user?)
  • A map of your narrative with the forking paths of decisions
  • One image of a possible scene/space for your story

Tip: Location-Based Story Idea

If you are having trouble coming up with a story, you could make it location-specific. Define one or more locations in NYC that you find interesting. Document the location(s) with several photographs. Write a brief story about the location(s) and give it alternate paths. The story may document something that happened at the location or something more fantastic. Give your user choices to move through the location(s), perhaps something different happens in the story or to your user based on the choices.
