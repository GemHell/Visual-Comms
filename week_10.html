Week 10: Introduction to Web Development

HTML Vocabulary

  • HTML – HyperText Markup Language. The standard language used to structure content on web pages. It tells the browser what each piece of content is (a heading, a paragraph, an image, a link, etc.).
  • Tags – Keywords wrapped in angle brackets, like <p>, that mark where a piece of content begins and ends. Most tags come in pairs: an opening tag (<p>) and a closing tag with a slash (</p>).
  • Elements – The complete unit made up of an opening tag, the content inside it, and a closing tag. For example, <p>Hello!</p> is a paragraph element. Some elements, like <img>, have no closing tag.
  • Repository – A folder that holds all the files for a project (HTML, CSS, images, etc.) along with a history of every change made to them. Repositories are often stored online on sites like GitHub so they can be shared and published.

HTML Boilerplate

Every HTML page starts with the same basic structure. Copy this into a new file to get started.

<!DOCTYPE html>
<html>
<head>
    <title>Website Title</title>
</head>
<body>
    This is my first web page
</body>
</html>

HTML Examples

Below are some basic HTML tags you'll use to build your pages, along with an example of each.

Paragraph

Use the <p> tag to create a paragraph of text.

<p>This is a paragraph.</p>

Heading

Use heading tags (<h1> through <h6>) to create titles and section headings, with <h1> being the largest/most important.

<h1>This is a heading</h1>

Bold

Use the <strong> tag to make text bold and emphasize its importance.

<strong>This text is bold</strong>

Italic

Use the <em> tag to italicize text and emphasize it.

<em>This text is italic</em>

Link

Use the <a> tag with an href attribute to create a hyperlink to another page.

<a href="https://example.com">This is a link</a>

Image

Use the <img> tag with src and alt attributes to display an image on your page.

<img src="images/photo.jpg" alt="Description of photo">
