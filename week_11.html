Week 11: Intro to CSS

What is CSS? (From W3Schools.com)

CSS is the language we use to style a Web page.

  • CSS stands for Cascading Style Sheets
  • CSS describes how HTML elements are to be displayed on screen.
  • CSS saves a lot of work. One CSS stylesheet can control the layout of multiple web pages all at once
  • External stylesheets are stored in CSS files

CSS Vocabulary

We write CSS rules to style our HTML elements. A CSS rule is made up of a selector followed by curly braces { } that hold one or more properties. Each property is given a value. A semicolon (;) is placed after the value of each property.

selector {
    property: value;
}
  • Selectors: Specify which HTML elements a rule applies to. For example, p targets every paragraph and h1 targets every main heading.
  • Properties: The aspect of the element you want to change, such as color, font-size, or background-color.
  • Values: The setting you give a property, such as red, 16px, or center. A colon : separates the property from its value.

For example, if I wanted to style my paragraph elements with italic, blue text, that is twice the size of the current text I would write it like this:

p {
    font-style: italic;
    color: blue;
    font-size: 2em;
}

Creating your Style Sheet

Create a new text file and name it style.css. Save it in the same folder as your index.html file. Copy this template into it to get started.

body {
    background-color: white;
    color: black;
    font-size: 16px;
    line-height: 1.5;
    font-family: Arial, Helvetica, sans-serif;
}

h1 {
    font-size: 32px;
}

p {
    font-size: 16px;
    font-style: normal;
}

a {
    color: blue;
    text-decoration: none;
}

Linking your Style Sheet to your index.html File

Add a <link> tag inside the <head> of your index.html file. The href is the name of your CSS file.

<!DOCTYPE html>
<html>
<head>
    <title>Website Title</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    This is my first web page
</body>
</html>

About property values:

  • Font-size can be defined in different units (px, pt, em, rem, etc.). Read more about the different units here.
  • Color values can be specified in different ways (Predefined color names, hex, rgb, etc.). Read more about color values here.
  • Font-family can be a single font or a list of fonts. Any font listed after the first is called a fallback font (see the CSS example above). Not all computers have the same fonts installed. Fallback fonts give the browser other options if the primary font is not available. Because not all users will have the same fonts installed, it's usually wise to default to common fonts and provide fallback options. More on font-families here.
