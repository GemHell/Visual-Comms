Week 12: Combining CSS and HTML

Reusable UI Elements with divs, classes, and ids

Today we're building a simple dialogue box but you can use all the principles we cover to create other reusable UI elements.

I've never seen this path before...

To get there, we'll cover:

  • CSS selectors, classes, and ids
  • Div elements in HTML
  • The div box model

The dialogue box pulls all of them together in a single, reusable class.

The <div> Element

A <div> is a generic, block-level container. It has no visual appearance of its own: no color, no border, no size. Its job is to wrap content so you can target and style it as a unit with CSS.

Our dialogue box starts as a bare div with text inside:

<div>I've never seen this path before...</div>

Right now it looks like plain text. To style it, we need a way to connect it the our CSS rules, which means giving it a class.

<div class="dialogue-box">I've never seen this path before...</div>

Now CSS can find it. The class is the hook that connects the HTML to the stylesheet.

CSS Selectors: Type, Class, and ID

CSS selectors tell the browser which HTML elements to style. There are three fundamental types.

Type Selectors

A type selector targets every element of a given tag. A rule for div applies to every div on the page, useful for broad defaults but too broad for a specific element like our box.

div {
    font-size: 60px;
}

Class Selectors

A class selector targets any element with a matching class attribute. In CSS, class names are preceded by a period . — this is how we'll style the dialogue box. Write the rule once, apply it to as many divs as you need.

.dialogue-box {
    background-color: rgb(194, 194, 255);
    border-radius: 60px;
    padding: 12px 16px;
}

In your HTML:

<div class="dialogue-box">I've never seen this path before...</div>
<div class="dialogue-box">We should turn back.</div>

ID Selectors

An ID selector targets one unique element. IDs are preceded by # and should only appear once per page. Use them for page-specific overrides. For example, positioning a box differently on one particular scene.

#scene-3-box {
    position: relative;
    top: 40px;
    left: 60px;
}

Quick Reference

Selector Syntax (how to type it) Targets
Type div { } All <div> elements
Class .dialogue-box { } Any element with class="dialogue-box"
ID #scene-3-box { } The one element with id="scene-3-box"

The Box Model

Every HTML element, including our dialogue box div, is treated by the browser as a rectangular box. The CSS Box Model describes the layers that make up that box, from the inside out:

  • Content: the text inside the box. (The default value for divs is "auto" which wraps the div to the content)
  • Padding: the space between the text and the div's border
  • Border: the line separating the inside and outside of the div
  • Margin: the space separating the border from neighboring elements
.dialogue-box {
    padding: 12px 16px;
    border: 2px solid #333333;
    border-radius: 60px;
    margin: 10px;
}

You can play around with these properties in this interactive box model demo at w3schools.com: CSS Box Model.

Helpful Snippets to Copy

Change Link Appearance on Hover

The CSS :hover pseudo-class is used to style elements when a user hovers their cursor over them. This is a great way to provide visual feedback to users, making your site more interactive and responsive.

For example, you can change the color of a link when someone hovers over it:

a:hover {
    color: #ff0000;
    text-decoration: underline;
}

For more information about the hover pseudo-class and how to use it, visit the W3Schools reference on the CSS :hover selector.

More about pseudo-classes: W3Schools reference on CSS pseudo-classes

Open Links in a New Window

The target="_blank" attribute in HTML links is used to specify where a linked document should open. When you set target="_blank", the link will open in a new browser tab or window, leaving your current page open. This is useful when you want to direct users to external resources without losing their place on your site.

For example:

<a href="https://example.com" target="_blank">Visit Example</a>

For more information about the target attribute go to the W3Schools reference on the target attribute.
