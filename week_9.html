Week 9: Website Recreation in Illustrator

Exercise 8: Recreate a Popular Website

"Good artists borrow, great artists steal." - Pablo Picasso (maybe)

Choose a website that you visit often and recreate its visual design in Adobe Illustrator. You might choose Google, YouTube, Instagram, Netflix, Spotify, or another site that you use regularly.

The goal is not to build a working website. Instead, study how the original site organizes information and use Illustrator to reproduce its layout, hierarchy, color, typography, spacing, and interface elements as accurately as you can.

Your Recreation

Create two separate pages from the same website:

  • Two different desktop pages, such as a home page and a search or profile page
  • Or one desktop page and one mobile version of the same site

For example, a YouTube recreation could include the home page and a video watch page. An Instagram recreation could include the feed and a profile page. Choose pages that let you show different types of layout and interaction.

Process

  1. Select your website and identify the two pages you will recreate.
  2. Collect reference images by visiting the site and taking screenshots. Pay attention to the grid, margins, navigation, type scale, colors, icons, and repeated components.
  3. Set up an Illustrator document with an artboard for each page. Use a standard desktop size such as 1440 x 900 pixels or a common mobile size such as 390 x 844 pixels.
  4. Build the large structure first: background, header, navigation, columns, cards, and content areas.
  5. Refine the details: typography, buttons, links, logos, icons, borders, shadows, and spacing.
  6. Compare your work with the original at the same scale and make a final pass for alignment and consistency.

Separate Asset Artboards

In addition to the two page artboards, create separate artboards for reusable interface assets. Include at least:

  • One logo or wordmark
  • Two buttons or button states
  • Two links or link states
  • Two icons or other small interface elements

Label each asset artboard clearly. Keep related assets together and make sure the individual elements are easy to select and inspect.

What to Submit

  • One organized Illustrator file (.ai) containing both recreated pages and the separate asset artboards
  • A PDF export showing all artboards
  • Reference screenshots of the original pages for comparison
