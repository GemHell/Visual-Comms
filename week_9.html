What is a Gif?

GIF stands for Graphics Interchange Format. GIF is a raster file format designed for relatively basic images that appear mainly on the internet. Each file can support up to 8 bits per pixel and can contain 256 indexed colors. GIF files also allow images or frames to be combined, creating basic animations.
from Adobe.com

Basically it's a simple animation that often loops.

Making an Animated Eye

The Illustrator to Photoshop to Gif Pipeline

To make an animated gif, we will be using both Adobe Illustrator and Photoshop. The process is as follows:

In Illustrator

  1. Open your eye illustration
  2. Make sure the eyelid is on a separate layer from the rest of the image.
  3. Go to file > export > export as
    • change the format to Photoshop (psd)
  4. Export

In Photoshop

  1. Open the exported PSD file
    • The layers from your Illustrator file should be preserved.
  2. Duplicate the eyelid layer to create separate frames. For each layer, use the move or resize tool to move the lid slightly down. 4 or five layers should do.
    • Repeat this step in reverse to animate the lid opening again.
  3. Go to window > timeline. (the timeline panel should appear at the bottom of your workspace)
  4. Select all of your layers. (shift click)
  5. In the timeline panel, click the dropdown and select "create frame animation"
  6. In the timeline panel menu, select "make frames from layers"
  7. Select your background layer. (This will most likely be your eyeball and pupil)
  8. In the timeline panel, click the dropdown and select "Match layer across frames"
    • You will most likely have to delete your first frame after doing this
  9. Set the delay time for each frame to 0.1 seconds (or whatever you like). This is the down arrow at the bottom of each frame.
    • You can do this all at once by selecting multiple frames and adjusting the delay time together. (shift click)
  10. Set the looping option to "forever"
  11. Press play to view your gif!
  12. Make adjustments to delay time as needed.

Exporting Your Gif

  1. Go to file > export > save for web
  2. Change the format to GIF
  3. Set colors to lowest number that preserves your color scheme. (This saves file space)
    • You can monitor file space in the bottom left corner.
  4. You can select "Transparency" if you want a transparent background. If not, the background will be solid.
  5. Make sure convert to sRGB is selected for posting to the web.
  6. Make sure the looping option is set to "forever"
  7. Click Save

    8. Adding Your Gif to Your Website

    To add your gif to your website, you can use the same code you would use to add a static image:

                    <img src="images/eyeball.gif" alt="animated gif of an eyeball blinking" width="400vw">

    Just make sure to change the file path and alt text to match your gif.

  • Create photographs of yourself or friend(s). Be sure to photograph against a high-contrast solid background to make it easier to "pull off" the figure.

  • Use Puppet Warp Tool to animate the cropped photography

  • In each frame create variations of the person using the Puppet Warp tool
  • Open the Timeline panel and create a "Frame Animation"
  • Present each layer on different frames to create an animation of you or a friend in various positions
  • Add background layers, more people or text... Have fun with it!
